# Zaid Creative Studio

Graphic designer portfolio with a public gallery and owner-only management.

## Owner workflow
1. Open /manage and sign in with the ChatGPT account for bajeerzaid@gmail.com.
2. Choose Add project. Export Photoshop/Illustrator artwork as JPG, PNG or WebP first (up to 10 MB).
3. Add a title, category, tools and description, then Save project.
4. Projects are stored online in R2 and appear on the public gallery.
5. Use Edit project, Delete or Your profile to update content. Keep your own original design backups.

Only the configured owner email can mutate content, checked on every server request. Do not remove the Sites authentication integration. Public visitors can read the portfolio without signing in. The gallery supports up to 1,000 projects. Placeholder artwork is explicitly marked as layout previews and disappears after real projects are uploaded.

## Development
Use the Sites helpers to install dependencies and build. This project uses the supplied Vinext starter with the BUCKET R2 binding. No D1 database or external API keys are required.
